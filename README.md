# Fluid Scaling Calculator

https://fluid-scaling-calculator.cromero.io/

This is a small single-page tool that writes a CSS clamp() value for fluid type. You enter a minimum size, a maximum size and a maximum viewport width. It produces a declaration such as clamp(3rem, 6.67vw, 5rem) that you can copy with one click, and it shows a live text preview at that size. You can switch between rem and px, edit the preview text, and expand the preview pane to full width.
